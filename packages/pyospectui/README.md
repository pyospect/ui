# pyospectui

고경표의 취향을 담은 AI 친화적 디자인 시스템이에요. shadcn 프로젝트에서 한 줄로 시작해요.

```bash
npx pyospectui
```

테마와 컴포넌트 19개가 전부 들어와요. 몇 개만 고르려면 이름을 붙여요.

```bash
npx pyospectui button card thinking
```

shadcn이 만든 기본 button이 이미 있으면 `--overwrite`를 붙여요. 규칙은 https://ui.pyospect.com/TASTE.md, 데모는 https://ui.pyospect.com 이에요.

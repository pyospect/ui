# pyospectui 사용 규칙

디자인 값의 정본은 [DESIGN.md](https://github.com/pyospect/ui/blob/main/DESIGN.md)다. 이전 v0.3의 초록 기본색, 400/500/600 굵기와 고정 8/12/20 반경 단계는 2026-10-25에 아래 기준으로 교체했다. 20px 같은 안쪽 반경은 아래 동심형 계산에서 다시 나올 수 있다.

- 한글과 영문 모두 Pretendard Medium 500. 제목 36px, 행간 1.2, 자간 -0.05em. 로고는 자간 0이다.
- 설명 본문은 `brand-copy`로 14px, 행간 1.85, 자간 -0.015em을 쓴다. 긴 소개문은 16px, 행간 1.8로 읽기 편하게 둔다. 라벨과 버튼의 굵기는 계속 500이다.
- 카드 기본 padding과 CardBody padding은 24px, 내부 간격은 20px다. 미디어 카드의 바깥 padding 4px는 유지한다.
- 대화 간격은 18px다. 에이전트 말풍선은 15px / 1.85와 padding 16px 18px, 사람 말풍선은 14px / 1.5와 padding 12px 18px를 쓴다. 자간은 -0.015em이다.
- 기본 간격은 4px 단위를 쓰되, BrandStudio의 15px 대화 글자와 18px 대화 간격·가로 padding은 명시적인 예외다. 이를 임의로 16px나 20px로 반올림하지 않는다.
- 섹션 여백 56px. 화면 크기에 따라 제목 크기를 나누지 않고 좌우 여백과 열 수를 조정한다.
- 독립된 카드, 입력창, 패널의 기본 바깥 반경은 24px다. 버튼은 full, 말풍선은 22px다.
- 바깥 윤곽을 일정 간격으로 따라가는 안쪽 면에는 동심형(concentric) 규칙을 적용한다. 안쪽 반경은 max(0px, 바깥 반경 - 간격)이다. 카드 24px와 이미지 사이가 4px면 이미지는 20px, 실험실 카드와 캔버스 사이가 12px면 캔버스는 12px다. List와 Select 팝업의 4px 안쪽 행도 20px다.
- 패널 안의 독립된 입력창이나 버튼, 중앙의 썸네일은 부모 윤곽에 맞물리는 면이 아니므로 자기 역할의 24px 또는 pill을 유지한다. 모든 자식에게 같거나 작은 반경을 무조건 주지 않는다.
- 동심성은 [필수 QA 항목](https://github.com/pyospect/ui/blob/main/docs/QA.md)이다. pill 버튼은 실제 짧은 변의 절반을 반경으로 쓰고, 일반 카드·패널은 현재 기본 상한 24px에서 과도한 라운딩을 검토한다. 짧은 박스의 CSS 반경 축소까지 고려한 유효 반경을 실측하고 `npm run check:geometry -- <측정 JSON>`으로 확인한다. 모든 면을 높이의 절반으로 만들지 않는다.
- light는 #fafafa 배경과 흰 카드, dark는 #0a0a0a 배경과 #171717 카드다. 본문은 light #525252 / dark #d4d4d4다.
- 일반 border는 없거나 black/white 10%다. focus와 의미 있는 상태선은 별도 토큰으로 선명하게 유지한다. 카드 그림자는 쓰지 않는다.
- UI에 기본색 hex나 Tailwind 색상 팔레트를 직접 쓰지 않고 역할 토큰을 사용한다. 작품 이미지와 배경 실험실의 팔레트 데이터는 예외다.
- 기본 pyospect 브랜드는 neutral #171717. 색조가 있는 프리셋과 custom seed는 기존 OKLCH 규칙을 따른다. 기본 neutral seed를 제외한 저채도 색은 받지 않는다.
- `X-text`는 `X`, `X-hover` 위에서 4.5:1 이상이다. brand-ink는 표면 위에서 4.5:1과 APCA 60 이상, brand-graphic과 의미 있는 line은 3:1 이상이다.
- 일반 input 경계의 10% 투명도는 장식 역할이다. 라벨, 면 차이, focus, 오류 표시로 식별하며 `line` 의미선의 3:1 규칙을 장식 border에 적용하지 않는다.
- 기본 UI의 초록 기운은 제거한다. artwork와 상태색, 선택해서 사용하는 컬러 프리셋까지 흑백으로 바꾸지는 않는다.
- 한국어는 단어 단위로 줄을 나누고 문장은 해요체로 쓴다. 버튼은 수행할 행동을 설명한다. 장식용 대문자 나열은 쓰지 않는다.
- 제품의 선택 목록은 Radix 기반 Select를 쓴다. 트리거와 열린 목록 모두 역할 토큰을 따라 밝은 모드와 다크 모드가 일치한다. OS가 그리는 native select 팝업을 CSS로 완전히 맞춘다고 가정하지 않는다.
- 드롭다운 쉐브론은 16px, 오른쪽 12px, 수직 중앙에 둔다. 긴 선택값과 겹치지 않게 오른쪽 여백을 확보한다. 팝업은 바깥 반경 24px와 padding 4px, 항목은 안쪽 반경 20px를 쓴다. 방향키, Enter, Escape와 포커스 복귀를 유지한다.
- 터치 영역은 최소 24px, 주요 모바일 조작은 44px 이상을 권장한다. focus는 2px, offset 2px다. reduced-motion을 존중한다.
- 모션은 120ms ease-out, 색과 투명도 중심이다. 과도한 크기 변화와 카드 shadow는 피한다.
- 읽어야 할 카드 제목, 빈 화면 안내, 대화, 검증 이유, 생각 과정, 연결 상태 안내는 줄바꿈한다. 버튼과 배지, 목록 행의 라벨과 짧은 메타데이터는 공간 안에서 말줄임하고 페이지 밖으로 밀어내지 않는다.
- Dialog는 화면 높이 안에서 스크롤하며 긴 질문과 행동 버튼이 잘리지 않게 줄바꿈한다. 좁은 화면의 단계 목록은 한 열로 놓고 가로 연결선을 숨긴다.
- 테이블과 코드, 명령어의 긴 줄은 해당 영역 안에서 가로 스크롤한다. 표의 셀, 상태 태그, 짧은 라벨과 메타데이터는 조밀한 정보 영역이므로 12~14px와 명시적 행간을 유지한다. 본문 16px와 행간 1.8을 모든 컨트롤에 일괄 상속하지 않는다.
- 대화에서 사람과 에이전트는 정렬과 형태, 라벨로 구분한다. 색만으로 누가 말하는지 알리지는 않는다.
- 컴포넌트 첫 주석은 Naming, Variant, Token, Structure, Usage Rule 순서로 쓴다. 데모 데이터는 명백한 가상 값이다.

자세한 토큰표, 다크모드, 배경 실험실과 릴리스 범위는 DESIGN.md를 본다. 프리셋별 실제 생성값과 대비표는 `/themes/<preset>.md`, 프리셋 목록은 `/themes/index.md`에 생성한다.

## 20. 브랜드 색 생성 규칙

R1: 기본 neutral #171717은 고정 gray 스케일과 light/dark 역할 반전을 쓴다. 다른 seed는 OKLCH C 0.04 이상이어야 한다.
R2: 유채색 스케일은 고정 L 배열에 seed chroma 비율을 적용하고 sRGB gamut 안으로 맞춘다.
R3: fill은 흰 글자 AA 경계로 정한다. 밝은 seed는 검은 글자를 쓰고 필요하면 fill 명도를 올린다.
R4: 원래 seed가 fill이 아니면 해당 명도에 가까운 스케일 단계에 보존한다.
R5: hover는 fill 위 글자가 AA를 유지하는 톤이다.
R6: ink는 표면과 tint 위 WCAG 4.5:1, APCA 60을 모두 만족한다.
R7: tint는 surface에 불투명 혼합하고 surface-2와 dE-OK 0.0184 이상 구분한다.
R8: graphic은 surface와 bg 위 3:1 이상을 만족하고 부족하면 ink를 사용한다.
R9: 상태색은 자기 hue 범위에서 brand와 30도 간격을 확보한다. 확보할 수 없으면 경고하며 라벨과 모양으로 뜻을 전달한다. neutral brand에는 hue 충돌이 없다.
R10: chart는 hue 간격을 두고 밝은 면과 어두운 면에서 3:1 이상을 검사한다.

구현과 정확한 수식은 packages/pyospectui/theme/generate.mjs, 판정 기준은 contract.mjs, 회귀 검사는 scripts/theme-check.mjs에 있다.

pyospectui

저는 생각한 것을 직접 만드는 사람이에요. 화면으로, 문장으로, 코드로요. 조용한 밤에 화면 하나를 붙잡고 여백과 문장의 온도를 다듬을 때 가장 몰입하고, 그렇게 만든 것이 누군가의 손에 닿아 반응으로 돌아올 때 의미를 느껴요.

이 시스템은 그 습관을 AI에게 건네주려고 만들었어요. 사람이 결정할 일과 시스템이 처리할 일을 나누고, 쓰는 사람이 덜 불안하게 다음 행동을 고를 수 있도록 다듬는 것. 기술이 삶에 닿는 마지막 한 뼘을, 누구나 설치 한 줄로 시작할 수 있으면 좋겠어요.

고경표, Product Designer. 정책과 데이터와 AI가 얽힌 화면에서 사람이 이해하고 결정할 수 있는 구조를 만들어요.

다섯 가지 기준AI가 디자인 시스템을 읽을 수 있으려면 이 다섯 가지가 갖춰져 있어야 해요. 모든 컴포넌트 문서는 이 순서로 써요.

Naming

이름만 보고 역할과 맥락을 알 수 있어야 해요. Button/Primary처럼 위계가 이름에 들어가요.

Variant

상태와 옵션은 property로 분리해요. hierarchy, size, state, icon 네 축을 넘기지 않아요.

Token

raw 값 대신 의미 토큰만 써요. #0B7A5E가 아니라 accent, 16px가 아니라 sp-4예요.

Structure

어떤 컴포넌트가 어떤 컴포넌트 안에 들어갈 수 있는지 정해져 있어요. 카드 안에 카드는 못 들어가요.

Usage Rule

언제 무엇을 써야 하는지 적혀 있어요. 되돌릴 수 없는 결정은 dialog, 되돌릴 수 있는 결과는 toast예요.

Structure글자 하나와 아이콘 하나까지만 들어가요. 버튼 안에 태그나 두 줄 글은 못 들어가요. 한 줄이 넘치면 말줄임표예요.

RulesAI에게 그대로 주는 규칙이에요.

  • Grid간격과 크기는 전부 4의 배수예요. 글자 크기 14만 예외이고, 그 줄 높이 20이 리듬을 지켜요.
  • TypePretendard 400, 500, 600만 써요. 기본은 500이고, 위계는 크기보다 톤과 굵기로 내요.
  • Text줄바꿈은 단어 단위예요. 태그, 버튼, 제목, 라벨처럼 한 줄이어야 하는 UI는 두 줄로 꺾지 않고 말줄임표예요. 라벨과 컨트롤 쌍은 갈라지지 않고, 좁으면 라벨이 먼저 줄어들어요. 콘텐츠가 카드 밖으로 나가지 않아요.
  • Writing친절하게 풀어쓴 해요체예요. 명사로 끝내지 않고, 영어 직역 말투를 쓰지 않아요. 버튼은 동사, 숫자는 콤마와 원, 날짜는 ISO예요.
  • Copyem dash와 가운뎃점을 쓰지 않아요. 쉼표와 마침표, 콜론으로 충분해요. monospace는 UI 글에는 없고, 코드와 diff, 토큰 값에만 JetBrains Mono예요.
  • Color순수 무채색 4단계 면에 brand 스케일 하나, 상태색 셋이에요. accent 채움은 brand-600에 흰 글자, 글자와 링크는 brand-700이에요. 색이 있는 pill은 단색에 흰 글자예요. tint는 면에만 쓰고, 반투명이 아니라 surface에 섞은 불투명 색이라 뒤가 비치지 않아요. 색조 있는 면 위에는 뉴트럴 회색 채움을 올리지 않아요. 글자와 accent는 AA 4.5:1을 넘겨요.
  • Surface영역은 톤 차이로 나눠요. 선은 input, 스위치 트랙, focus, 선택, 오류처럼 의미가 있을 때만 line 토큰으로 써요.
  • Elevation그림자는 overlay에만 있어요. 다크에서는 그림자 대신 glow예요.
  • Depthbg 위에 surface, 2겹까지예요. 카드 속 카드는 없어요. 테이블이나 리스트처럼 이미 surface인 컴포넌트는 패널에 넣지 않고 bg 위에 바로 놓아요.
  • Radiusfull 아니면 12예요. 겹치면 바깥 r은 안쪽 r에 padding을 더한 값이에요.
  • IconLucide, 선 굵기 1.5, 크기 16과 20이에요. 옆 글자와 같은 색이고 채운 아이콘은 없어요.
  • Layout왼쪽 정렬이 기본이에요. 폭은 720, 1040, 1280 중 하나이고 라벨은 항상 input 위예요.
  • Motion120ms ease-out 하나예요. 색과 투명도만 움직여요.
  • A11y키보드로 모든 것에 닿아요. focus는 2px 선, 터치 영역은 24 이상, 모바일은 44예요. 오류는 aria-invalid와 설명 연결이 있어요.
  • AI모든 컴포넌트에 Naming, Variant, Token, Structure, Usage Rule 다섯 줄이 있어요. 에이전트가 처리한 것과 사람이 결정할 것은 항상 모양이 달라요.
